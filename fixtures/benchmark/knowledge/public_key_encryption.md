# Public-Key Cryptography

Public-key cryptography (asymmetric cryptography) uses pairs of mathematically related keys: a public key and a private key.
The public key is openly distributed and used by senders to encrypt plaintext messages.
Only the corresponding private key, kept confidential by the recipient, can decrypt the ciphertext.
Common asymmetric algorithms such as RSA and Elliptic Curve Cryptography rely on one-way mathematical functions that are easy to compute but computationally intractable to invert without the private key.
